Questions

Does Pluks record my keystrokes?

No. The keyboard listener Pluks already uses for select-to-copy only learns that a key was pressed and which kind (typing, delete, enter). After you pause, Pluks reads the text box once through macOS Accessibility — the same way a screen reader would — and saves it on your Mac.

Which apps does it work in?

Anything with a standard macOS text field or text area: Safari, Chrome, Arc, Edge and Brave (including ChatGPT, Claude and Gmail), Slack, Discord, Notion, Notes, Mail, Messages and more. Rich text comes back as plain text. Google Docs is not covered — it draws on a canvas and autosaves anyway.

Windows?

Draft Recovery is macOS-only for now; Windows support is being built. A lifetime license will cover it when it ships.

What happens after the trial?

New drafts stop being saved. Everything already saved stays readable until it expires — we never hold your text hostage.
