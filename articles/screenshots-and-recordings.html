WORKFLOW GUIDE · 3 MIN READ

Move screenshots and recordings between apps without hunting for files

A capture is often created to share immediately. The faster workflow is to keep the capture ready to paste or attach instead of searching through a screenshots folder.

By Pluks · Published September 21, 2026

Screenshots work best as image clips: capture them, keep them ready, and paste them into the chat, issue, document, or email where they belong. Screen recordings are different: they are large files, so the useful action is usually to retain a file reference and attach the recording without duplicating its bytes.

Use image clips for screenshots

When a screenshot is on the clipboard, an app that accepts images can often paste it directly. This is ideal for a bug report, a design comment, or a short explanation to a teammate. Pluks can automatically add screenshots to history and put them on the clipboard, so an image capture follows the same retrieval workflow as text.

Use file clips for recordings

Screen recordings can be too large to treat like ordinary clipboard text or image data. Pluks stores a file clip that points to the recording on disk. Pasting that file clip works like copying the file in Finder or Explorer, which is the right behavior for attaching it to a message or moving it in a file manager.

Keep capture history useful

The point is not to store every capture forever. Use history to bridge the few minutes between capturing something and putting it to work. Search for the screenshot or recording when you are ready, then clear clips that no longer need to be close at hand.
